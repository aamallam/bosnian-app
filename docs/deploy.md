# Deploying the staging API (free tier)

Everything here costs $0 (ADR 0010). You do these steps yourself in each
provider's dashboard; no secret ever goes into git.

## 1. Database: Neon
1. Sign up at neon.com and create a project in **AWS Europe (Frankfurt)**, Postgres 16 or newer.
2. Create a database `langex`.
3. Copy the **direct** connection string (not the pooled one), for example
   `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/langex?sslmode=require`.

## 2. API: Render
1. Sign up at render.com with GitHub and allow access to this repository only.
2. **New → Blueprint**, pick the repository. Render reads [`render.yaml`](../render.yaml).
3. When asked, paste:
   - `LANGEX_DATABASE_URL`: the Neon string from step 1;
   - `LANGEX_GOOGLE_CLIENT_IDS` and `LANGEX_APPLE_CLIENT_IDS`: from step 3 (they can stay empty at first).
   `LANGEX_JWT_SECRET` is generated by Render.
4. Deploy. Check `https://<your-service>.onrender.com/healthz` returns `{"status":"ok"}`
   and `/readyz` returns `{"status":"ready"}` (this one wakes the database).

Every push to `main` deploys again. Migrations run when the container starts.

## 3. Sign-in providers
Until at least one is set, nobody can sign in to staging (dev sign-in is refused there).
- **Google** (free): Google Cloud Console → APIs & Services → Credentials →
  OAuth client IDs for Android (package name + SHA-1) and iOS (bundle ID).
  Put all client IDs in `LANGEX_GOOGLE_CLIENT_IDS`, comma-separated.
- **Apple** (needs the $99/year Apple Developer Program): enable Sign in with
  Apple for the app ID; put the bundle ID in `LANGEX_APPLE_CLIENT_IDS`.

## 4. Before real users
- Turn on a **billing alert** in Cloudflare (R2) once audio storage is added.
- Add Sentry (free) for error reports with personal-data scrubbing.
- Follow the [launch checklist](security/baseline.md#launch-checklist).

## Local development
```
cp infra/.env.example infra/.env   # add a random LANGEX_JWT_SECRET
docker compose -f infra/docker-compose.yml up --build
```
Open http://localhost:8000/docs and sign in with provider `dev`, token `dev:<any-name>`.

Without Docker: `cd backend`, set `LANGEX_JWT_SECRET` and
`LANGEX_ALLOW_DEV_SIGN_IN=true`, run `alembic upgrade head`, then
`uvicorn langex.api.app:create_app --factory --reload` (uses a local SQLite file).
